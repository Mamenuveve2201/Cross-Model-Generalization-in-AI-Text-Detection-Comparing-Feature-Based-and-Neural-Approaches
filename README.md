\# AI Text Detector



Cross-model AI text detection using 41 hand-crafted linguistic features.

Trained on GPT-4o, Claude, Gemini, LLaMA, and Qwen with Leave-One-Model-Out cross-validation.



Built for CAP5638 Pattern Recognition at Florida State University.
